# Minhas Finanças - pacote para Netlify

Site estático (sem build). Arquivos: index.html, manifest.webmanifest, sw.js, _headers, netlify.toml e ícones.

## Publicar na Netlify
1. Acesse app.netlify.com/drop (precisa de conta gratuita).
2. Arraste esta pasta (ou o .zip) para a página.
3. A Netlify gera um endereço como https://nome-aleatorio.netlify.app (dá para trocar em Site configuration > Change site name).

## Instalar no iPhone
Abra o endereço no Safari > Compartilhar > Adicionar à Tela de Início.

## Importante
- Os dados ficam no aparelho (IndexedDB). Cada pessoa que abrir o link terá o próprio app, vazio, com os próprios dados.
- Faça backup em ⋮ > Dados e backup. Para migrar do Claude, exporte o backup lá e use Restaurar arquivo aqui.
- Para apresentar o app sem mostrar seus dados: ⋮ > Modo apresentação (dados fictícios, nada é salvo).
- O endereço não é indexado por buscadores, mas quem tiver o link consegue abrir o app. Use o bloqueio em ⋮ > Segurança.
